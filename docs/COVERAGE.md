The four browser scenarios include WCAG A/AA automated checks on discovery and authentication, keyboard Escape dismissal, viewports of 375/768/1024/1440px, and screenshot review. They also cover the seeded catalog, a restaurant's grouped menu, cuisine filter, safe image placeholder and the full four-role checkout flow against the seeded data.

The fictional catalog intentionally has no external data dependency. Its 70 raster food images are not generated in this workspace because no image-generation tooling is available; the UI shows a neutral "Ảnh đang cập nhật" placeholder and [the prompt guide](MOCK_IMAGE_PROMPTS.md) lists every required file and prompt. The asset test reports an explicit skip until those files exist.

Not implemented as real external services: commercial payment/refund settlement, maps/geocoding/GPS, email/SMS/push, multi-restaurant checkout, advanced complaints/refunds, capacity slots, promotions, legal KYC, payouts, or production backup automation. These are conditional or unresolved in the source and require business/provider decisions. The local app does not claim the preliminary 99.9% availability or production response-time target has been achieved.
